스쿨레이이드 방 생성·일시정지·답안 동기화 안정화 패치

GitHub에서 아래 3개 파일을 같은 경로에 덮어쓰세요.
- app/teacher/boss-battle/page.tsx
- app/student/boss-battle/page.tsx
- lib/boss-battle.ts

Supabase에서 추가 SQL을 실행할 필요는 없습니다.

주요 수정
1. 방 만들기 중 로딩 표시, 중복 클릭 방지, Supabase 조회/저장 시간 초과 및 오류 안내
2. 온라인 상태에서 Supabase 저장 실패를 localStorage 성공으로 오인하지 않도록 변경
3. 일시정지/재생 저장 실패 시 상태를 화면만 바꾸지 않고 오류 안내
4. 답안이 Supabase에 실제 저장된 경우에만 제출 완료 처리
5. 답안 조회 실패 시 빈 답안으로 판정하여 정답자를 오답 처리하지 않도록 변경
6. 살아 있는 학생 전원의 고유 ID가 실제로 제출되었을 때만 조기 진행
7. 저장된 is_correct 값과 기존 정답 판정 함수를 함께 확인하여 방어 정답 누락 방지
8. 학생 클라이언트의 참가자 heartbeat/전체 답안 Realtime 재조회 증폭 제거
9. 교사 진행 확인 주기를 200ms에서 800ms로 완화하여 DB 부하 감소

변경하지 않은 사항
- 문제 당 제한시간 명칭
- 정답 공개 시간 7초
- 가위바위보 선택 시간 20초
- 가위바위보 결과 시간 5초
- 방어 결과 공개 시간 4초
- 기존 보스 밸런스 및 피해량

검증
- npm run build 성공
